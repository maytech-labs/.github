# Contributing

Thanks for your interest. Open an issue before starting anything large.

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md). Report security bugs privately, as [SECURITY.md](SECURITY.md) says, not in an issue.

## Making a change

- Read the repo's own README and `CONTRIBUTING.md`, if it has one; they take precedence over this file.
- Add tests with the change.
- Write commit messages as terse [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/): `fix(lint): handle empty files`.
- Open the pull request against `main`. CI must pass.
